# S1-A — Static SEO X-ray design proof

This is an offline visual and interaction study, not the product. It reads only JSON generated from the repository's two SEO test HTML inputs by `backend.app.seo.engine.analyze_html`. It does not fetch a website, call FastAPI or Gemini, store report history, or contain credentials.

The controlled noindex comparison is generated by the same engine with explicit synthetic `X-Robots-Tag: noindex` fetch metadata. Its score and checks are engine output; the response-header condition is not a live fetch.

## Run locally on Windows

From the repository root, regenerate the three raw analysis outputs and supplementary source note:

```powershell
.\.venv\Scripts\python.exe docs/design/s1-a/generate_data.py
```

To confirm repeated generation is byte-for-byte stable:

```powershell
$before = (Get-ChildItem docs/design/s1-a/audit-*.json,docs/design/s1-a/offline-source-notes.json | Sort-Object Name | ForEach-Object { (Get-FileHash $_.FullName -Algorithm SHA256).Hash }) -join ','
.\.venv\Scripts\python.exe docs/design/s1-a/generate_data.py
$after = (Get-ChildItem docs/design/s1-a/audit-*.json,docs/design/s1-a/offline-source-notes.json | Sort-Object Name | ForEach-Object { (Get-FileHash $_.FullName -Algorithm SHA256).Hash }) -join ','
if ($before -ne $after) { throw 'Generated evidence changed between identical runs.' }
```

The automated suite starts a temporary HTTP server bound to `127.0.0.1`, uses the Playwright version already installed under `web/`, captures screenshots, performs browser checks, and shuts down the server:

```powershell
node docs/design/s1-a/check.mjs
```

After opening and inspecting all 27 screenshots at native dimensions, repeat with the review flag to record that manual inspection was completed:

```powershell
node docs/design/s1-a/check.mjs --visual-reviewed
```

For manual browsing, from the repository root in a separate PowerShell window:

```powershell
py -3.11 -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/docs/design/s1-a/proof-static-not-the-product.html?state=summary&sample=weak`. Stop the server with Ctrl+C. It listens only on loopback; do not bind it to a public interface.

Available states are `home`, `summary`, `on-page`, `previews`, `fix-list`, `loading`, and `error`. `sample=weak` and `sample=basic` select the two analyzer outputs. `sample=noindex` is the explicitly synthetic response-header comparison. A missing or unknown sample shows a recovery state and never substitutes another analysis.

## Data outputs

| File | Provenance |
|---|---|
| `audit-weak.json` | Direct `SEOAnalysis` from `tests/fixtures/weak.html` and fixed fetch metadata. |
| `audit-basic.json` | Direct `SEOAnalysis` from `tests/fixtures/basic.html` and fixed fetch metadata. |
| `audit-noindex-test.json` | Direct engine output from `weak.html` with synthetic `X-Robots-Tag: noindex`. |
| `enrichment.json` | Design-only impact, effort, anatomy mapping, plain-language action and editable snippet guidance. It does not alter analyzer results. |
| `offline-source-notes.json` | Supplementary local parsing of image `src` and line number from original test HTML. This is not returned by `SEOAnalysis`. |

Raw analysis JSON and presentation enrichment are separate. The analyzer does not return per-image attributes, arbitrary HTML excerpts, source line numbers, footer landmarks, target-keyword checks, or PageSpeed data; the proof does not claim them as API results.

## Checks

```powershell
node --check docs/design/s1-a/proof.js
node --check docs/design/s1-a/check.mjs
node docs/design/s1-a/check.mjs
.\.venv\Scripts\python.exe -m pytest tests/test_seo_engine.py
npm --prefix web run typecheck
npm --prefix web run lint
npm --prefix web test
npm --prefix web run build
git diff --check
```

`check.mjs` writes browser measurements and screenshot metadata to `evidence/verification.json`, `evidence/screenshot-index.json`, and `ACCEPTANCE.md`. It uses CSS viewport changes, not browser zoom. All browser requests are inspected and non-local destinations are blocked. This static proof does not verify any production behavior.
